One original word, written to `/output/entry.txt` by `main.py` (pure Python
standard library, no third-party imports).

## The word

> Sweetheart

The word a grandma says when you walk through her door — not a sentence,
not a speech, just the name she has called you since you were small enough
to sit on her lap.

## Run

```sh
python3 main.py
# writes entry.txt into $MAKEFUN_OUTPUT_DIR (default /output)
```
